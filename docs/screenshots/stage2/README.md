# 阶段二浏览器截图

本目录保存真实浏览器的实际截图及 browser-report.json。

- formal-empty-desktop.png、formal-empty-mobile.png：项目正式数据库的真实空页面。
- TEST_ONLY-results-*：独立虚构测试库的同名多候选结果。
- TEST_ONLY-profile-*：独立虚构测试库的人物规范档案。
- TEST_ONLY-evidence-*：独立虚构测试库的多条证据，分别标注本人自称和后世记载。

TEST_ONLY 文件中的人物、朝代、籍贯、古籍原文和 example.invalid 网址均为测试夹具，不是真实历史证据，不在正式数据库中。browser-report.json 记录 1440、390、320 像素视口的全部 18 项布局结果、JS 页面异常和正式库前后哈希。
