# 第七阶段古籍来源与许可记录

本阶段只保存明确允许本地保存与展示的数字化文本，并在阅读器中展示书名、
数字化版本、来源平台、许可与原始来源链接。

## 一、Kanripo 汉籍库

- 组织：<https://github.com/kanripo>
- 许可：CC BY-SA 4.0（以组织仓库说明为准）
- 版本：WYG（文渊阁四库全书）转录
- 采集方式：`git clone --depth 1`，按 2026-10-18 的仓库 commit 固定；每个文件
  保存 SHA-256，入库前与采集清单复核。
- 用途：保存完整的史传篇章；原文中的底本页标记、排版行与异体字不删改。

## 二、中文维基文库

- 站点：<https://zh.wikisource.org/>
- 许可：页面文本 CC BY-SA 4.0；古籍原作本身已进入公有领域。
- 采集方式：只抓取本阶段所需的 68 个史传页面；逐页限速、失败重试、保留
  页面标题、抓取时间、字节数与 SHA-256；能取得修订号时记录 `oldid`。
- 未批量抓取全站，不绕过访问限制；未使用中国哲学书电子化计划的正文。
- 页面示例（书名分布）：新唐書20、宋史14、舊唐書11、史記10、三國志4、
  漢書3、後漢書3、晉書1、南史1、新五代史1。

维基文库正文经过 `wikisource_wikitext_v1` 清理：移除模板、注释、表格、
分类/文件链接和编辑性标题；保留正文段落。清理不增删字句，章节标题作为
段落标签保存，不混入“原文”引文。

## 三、CBDB

- 中国历代人物传记资料库（CBDB）20250520。
- 许可：CC BY-NC-SA 4.0，仅供非商业用途。
- 用途：仅用于已有的身份、生卒、籍贯、别称等结构化资料；CBDB 记录不作为
  古籍原文，不与史传原文混计。相关来源在页面中明确标注为“结构化数据库”。

## 四、权利与标注规则

1. 古籍原作已进入公有领域，但现代数字化整理版本可能另有权利；本库只保存
   上列明确许可的版本。
2. 每个篇章保存来源 URL、平台、数字版本、许可、采集时间和文本哈希；阅读器
   页脚展示许可与原始来源。
3. 不从古籍原文中删除异体字、繁体字、阙文或版本差异；简繁转换只用于检索，
   原文本保持不变。
4. 未取得许可或无法核验的文本不进入正式库；仅在缺口报告中记录。
5. 本阶段没有使用模型记忆补写任何“古籍原文”。
